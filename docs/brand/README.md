# BailaCue · Watch. Practise. Repeat.

The play triangle is held by an open repeat loop: learning in motion. A small lime
cue dot gives the symbol a distinct finish. No trademark claim is made.

| Role | Colour |
| --- | --- |
| Deep plum · ink/icon | `#321D36` |
| Coral · warmth/illustration | `#FF8C74` |
| Cream · canvas | `#FFF6E8` |
| Lime · cue/highlight | `#D8F17D` |
| Dark coral · accessible light-theme actions | `#A53628` |

Outfit Semibold is the display face; DM Sans Regular/Medium/Bold is the interface
family. Both font packages include their licences. Coral/lime badges use plum text.
Do not set white text on the light coral. Controls use deeper coral for contrast.
Keep the icon background plum and reserve a clear area around the repeat symbol.

`assets/icon.svg` is the editable vector master. `npm run brand` generates the app,
adaptive, splash and favicon PNGs plus the identity board and Salsa/Bachata/status
badge SVGs. All assets are original vectors made for this project.
